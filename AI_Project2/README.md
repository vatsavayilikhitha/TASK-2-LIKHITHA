# AI Flower Classification Project

## Overview
This project is a Machine Learning based flower classification system using the Iris dataset.

The system predicts flower species using AI classification algorithms and provides a GUI for user interaction.

---

## Features
- Machine Learning Prediction
- GUI using Tkinter
- Prediction History
- Dark Mode
- User-Friendly Interface

---

## Technologies Used
- Python
- Tkinter
- Scikit-learn
- Pandas
- Matplotlib

---

## Files
- classification.py → Basic ML classification
- gui_classification.py → GUI version of project

---

## How to Run

Install libraries:

```bash
pip install scikit-learn pandas matplotlib
```

Run GUI project:

```bash
python gui_classification.py
```
